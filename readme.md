# 💻 Mi Portafolio Personal — Yeison Moran

¡Bienvenido a mi portafolio! Este es el repositorio central de mi sitio web personal, diseñado para presentar mis habilidades en desarrollo web, soporte técnico de TI y mis proyectos más recientes a reclutadores, clientes y colaboradores.

---

## 🚀 Sobre el Proyecto

Este portafolio es una ventana interactiva a mi perfil profesional. Combina un diseño web limpio y moderno con una presentación estructurada de mi trayectoria y proyectos.

### ✨ Características Clave:
* **Diseño Moderno e Interactivo:** Diseñado desde cero con CSS nativo, animaciones dinámicas (utilizando Typed.js para textos dinámicos y transiciones fluidas).
* **Totalmente Responsivo:** Adaptado a dispositivos móviles, tablets y pantallas de escritorio.
* **Acceso a mi CV:** Enlace directo de descarga para mi currículum en PDF.
* **Sección de Proyectos:** Galería visual con enlaces directos al código fuente de mis proyectos más importantes.

## 🛠️ Tecnologías y Herramientas

### En este Portafolio:

## 💻 Cómo Ejecutar este Portafolio Localmente

Si deseas explorar o visualizar este portafolio en tu máquina local:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/yeisonmoran/portafolio.git
   ```
2. **Navega al directorio del proyecto:**
   ```bash
   cd portafolio
   ```
3. **Abre el archivo principal:**
   Simplemente haz doble clic en `index.html` para abrirlo en tu navegador favorito, o utiliza una extensión de servidor local (como *Live Server* en VS Code).
